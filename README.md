# Finance Dashboard Portfolio Project

## Overview
A Power BI financial analysis dashboard showcasing data modeling, DAX formulas, and analytical insights.

## Key Metrics
- **Total Revenue:** £5.02M
- **Total Profit:** £6.49M  
- **Average Profit Margin:** 14.28%

## Dashboard Insights
- Revenue remained stable through 2023 but collapsed sharply in Dec-Jan
- All regions have thin, similar margins (13-15%), suggesting systemic pricing/cost issues
- Revenue is balanced across product categories but concentrated in the North region

## Technical Details
- **Data:** Sales transaction data with 2023 transactions
- **Calculated Columns:** COGS, Profit, Profit_Margin
- **DAX Measures:** Total Revenue, Total Profit, Avg Margin %
- **Visualizations:** KPI cards, trend line, regional/categorical breakdowns
